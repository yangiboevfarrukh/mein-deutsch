# Mein Deutsch

Личный тренажёр немецкого языка: карточки по категориям, грамматика от A1 до C1, голосовой режим с проверкой произношения, разговор с ИИ и домашние задания с проверкой.

Сборки нет. Три файла, обычный редактор, обновление страницы — и изменения на месте.

## Файлы

| Файл | Что внутри | Как часто вы будете это править |
|---|---|---|
| `index.html` | подключение библиотек, заголовок страницы | редко |
| `data.js` | все слова и все уроки грамматики | постоянно |
| `app.jsx` | интерфейс, голос, работа с ИИ | когда меняете логику или дизайн |

## Запуск на компьютере

Файл `app.jsx` загружается через `fetch`, поэтому просто открыть `index.html` двойным щелчком нельзя — нужен локальный сервер. Из папки проекта:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`. Альтернативы: `npx serve`, расширение Live Server в VS Code.

## Публикация на GitHub Pages

1. Создайте репозиторий на github.com, например `mein-deutsch`.
2. Загрузите в него `index.html`, `data.js`, `app.jsx`, `README.md` (кнопка «Add file → Upload files»).
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`, Save.
4. Через минуту сайт будет по адресу `https://ваш-логин.github.io/mein-deutsch/`.

Добавьте его на домашний экран телефона — откроется как обычное приложение.

Альтернативы без Git: перетащить папку на app.netlify.com/drop или запустить `vercel` в папке проекта.

## Как добавить слова

Откройте `data.js`, найдите нужную колоду и добавьте строку в её массив `words`:

```js
{ de: "die Anfrage, -n", ru: "запрос", ex: "Ich habe eine Anfrage geschickt.", exRu: "Я отправил запрос." },
```

`de` — то, что видно на карточке и что произносит диктор; пометки множественного числа вроде `, -n` при озвучке отбрасываются автоматически.

Новая колода — копия любого блока с уникальным `id` латиницей:

```js
{ id: "reisen", title: "Путешествия", de: "Reisen", hint: "Вокзал, аэропорт, отель", words: [ ... ] },
```

## Как добавить урок грамматики

Там же, в `data.js`, в массиве `GRAMMAR`:

```js
L("B1", "b1-7", "Название темы", "Суть одной строкой", [
  { h: "Заголовок таблицы", rows: [["левая колонка", "правая колонка"]] },
  { p: "Абзац объяснения." },
  { ex: ["Beispielsatz eins.", "Beispielsatz zwei."] },
]),
```

Первый аргумент — уровень, он должен совпадать с одним из значений `LEVELS`. Блоки `h`/`rows`, `p` и `ex` можно комбинировать в любом порядке и количестве.

## Как поменять оформление

В начале `app.jsx` находится объект `T` — вся палитра, и константы `SERIF` / `SANS` — шрифты. Меняете значение, обновляете страницу.

## Ключи и приватность

Ничего не зашито в код. Всё, что вы вводите, лежит в `localStorage` вашего браузера и уходит только на сервер выбранного сервиса.

- **Разговор с ИИ и домашние задания** — ключ Anthropic API с console.anthropic.com. Вводится на вкладках «Разговор» и «Домашка». Запрос идёт из браузера напрямую, поэтому включён заголовок `anthropic-dangerous-direct-browser-access`. Это нормально для личного сайта и небезопасно для публичного продукта: любой, кто откроет ваш браузер, увидит ключ. Никогда не вписывайте ключ в сам код перед загрузкой в репозиторий.
- **Голос** — работает без ключей на голосах системы. По желанию подключается Google Cloud Text-to-Speech или ElevenLabs, вкладка «Голос» → «Настройки голоса».
- **Прогресс** — выученные слова, пройденные темы и история домашних заданий хранятся только на устройстве. Очистка данных сайта их стирает.

## Что можно доделать

- офлайн-режим: service worker плюс заранее сгенерированные mp3 для колод, тогда аудио играет в метро при заблокированном экране
- интервальные повторения: хранить дату следующего показа карточки вместо флага «знаю»
- экспорт и импорт прогресса файлом, чтобы переносить между устройствами
- разбор ошибок: копить неверные ответы из домашки и собирать из них персональную колоду
